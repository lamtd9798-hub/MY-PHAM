Nhập file đơn hàng Shopee

Giai đoạn này chỉ cần file đơn hàng gốc xuất từ Shopee. Không cần báo cáo thu nhập hoặc sao kê ngân hàng.

📅 1. Chọn ngày muốn lưu dữ liệu

Ngày bạn chọn ở đây là ngày thống kê của kho dữ liệu. Sau đó mới chọn file buổi sáng hoặc buổi chiều.

-
Ví dụ: chọn 14/08/2026 → file sáng và file chiều đều được gộp vào dữ liệu ngày 14. Dữ liệu ngày khác vẫn được giữ riêng trên Supabase Cloud.
